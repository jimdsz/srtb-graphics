# Signal Precision

The visual identity is built around the quiet precision of a broadcast control room. Large fields of near-black give a single warm yellow room to act as a signal. The composition is meticulously crafted: every margin, baseline and intersection follows a deliberate rhythm, without ornamental interface chrome.

Typography carries the hierarchy. Instrument Sans supplies a direct, confident voice; Geist Mono provides the small technical annotations. Scale creates contrast, while carefully tuned spacing keeps the identity legible at the reduced width of a GitHub README. The finish depends on painstaking attention to proportion rather than decorative effects.

The abstract motif comes from a real production constraint: one composition must inhabit several frame formats. Landscape, portrait and vertical frames form a measured sequence, with a timeline beneath them. This is a graphic expression of the product, not an invented application screenshot or a performance claim.

Real interface captures follow the cover as evidence. Their native proportions and contents are preserved. English and French editions use the same grid and palette; each language receives its own carefully composed cover. The result should feel editorial, precise and recognisably connected to the application.

## Direction française

Noir profond, jaune chaud et typographie précise prolongent l’identité du studio. Les cadres évoquent les formats TV, portrait et vertical ; les captures montrent ensuite le produit réel. La structure reste identique dans les deux langues, sans recopier les visuels des projets étudiés.

The covers are original artwork. Instrument Sans and Geist Mono were used under the SIL Open Font License; no proprietary broadcast font files are distributed with these images.
