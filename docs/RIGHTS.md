# Rights and third-party components / Droits et composants tiers

## English

This is a public source portfolio. Publication does not grant a project-wide open-source licence. Branding, original graphic templates, fonts, media and third-party components retain their respective rights; no rights to SRTB/BTV marks are granted.

The licensed BeninSemiBold and SuisseIntl font files, production media, original template asset library and internal installers are excluded. Screenshots illustrate the application and do not distribute the underlying font or template files.

Existing dependency notices are preserved, including UI attribution in `src/studio/ui/THIRD-PARTY-NOTICES.md` and the FFmpeg notices and release block in `vendor/ffmpeg-core-0.12.10/`. The historical FFmpeg WebAssembly binary is excluded. The project includes additional media libraries; consult their distributed licences and the existing release checks before redistributing a built application. This snapshot does not remove or resolve those release requirements.

Les notices existantes sont conservées, notamment celles des composants d’interface et le blocage de publication du repli FFmpeg. Le binaire WebAssembly FFmpeg historique est exclu.
